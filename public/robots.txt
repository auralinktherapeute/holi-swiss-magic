# Annuaire suisse de thérapeutes holistiques (FR / DE / IT / EN)
#
# Un seul groupe « * » régit TOUS les robots, y compris les assistants IA
# (GPTBot, ClaudeBot, PerplexityBot, Google-Extended…). Les pages publiques
# sont ouvertes ; seules les zones privées/authentifiées sont exclues.
# (Avant : les Disallow étaient placés après une ligne vide dans un groupe sans
# user-agent valide, donc ignorés — les zones privées restaient crawlables.)

# Les chemins d'authentification emploient les segments FRANÇAIS dans les quatre
# langues (/de/connexion, /it/inscription…). Les anciennes lignes visaient des
# chemins localisés qui n'existent pas — /de/anmeldung, /it/accesso, /en/login —
# et étaient donc inertes : seules les variantes /fr/ étaient réellement
# couvertes, les pages DE, IT et EN restaient crawlables. Les motifs ci-dessous
# couvrent toutes les langues, présentes et futures.
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /dashboard/
Disallow: /creer-profil
Disallow: /*/connexion
Disallow: /*/inscription
Disallow: /*/mot-de-passe-oublie
Disallow: /*/reinitialiser-mot-de-passe
