# AGENTS.md

- Billing currency changes (practice `therapist_invoice_settings.devise_defaut` and client `crm_client_contacts.billing_currency`) go only through the `change_practice_currency` / `change_client_currency` RPCs, which log to the append-only `currency_change_consents`; a trigger blocks any other write. Why: consent and change must be atomic and auditable.
- Effective currency is resolved by `resolveEffectiveCurrency` (client → practice → CHF) in `src/lib/currency-consent.ts`; never re-derive it elsewhere. Why: one priority rule for invoices, bookings and UI.
- Blog variant indexability (robots, canonical, hreflang, sitemap) is decided only by `checkTranslation`/`articleIndexing` in `src/lib/article-translation.ts`; incomplete variants are noindex,follow with canonical to FR and never in the sitemap. Why: one rule for pages and sitemap, no silent French fallback indexed.
- The sitemap is an index (`/sitemap.xml`) over parts `/sitemaps/<part>.xml`, generated by `src/lib/sitemap-build.server.ts` and split by URL in `src/lib/sitemap-groups.ts`. Why: each part is monitorable separately in Search Console.
- Directory listing indexability (specialty, canton, city, family) is decided only by `isListingIndexable` in `src/lib/seo-thresholds.ts`, read by both route loaders and `sitemap-build.server.ts`; noindex pages emit canonical only (no hreflang, no business JSON-LD) and unknown cities with no active profile are 404. Why: one rule, sitemap never announces a noindex page.
- Institutional identity and translated pre-publication checks use `institutional-content.ts`; legal heads use its French-only canonical helper, and Organization remains in `organization-schema.ts`. Why: validated facts and legal indexability must not diverge across locales or pages.
- Indexing-tracking data (dedicated project tables `indexed_urls`/`indexing_reports`) is read only server-side through `src/lib/indexation-source.server.ts`, exposed by `indexation-dashboard.functions.ts` (admin: assertAdmin; therapist: own profile from session only), and counted only by the pure `src/lib/indexation-metrics.ts`. Why: no browser access to the dedicated project, one counting rule, IndexNow never counted as indexed.
- The therapist-facing score is only the showcase score (`runShowcaseAudit` via `getMyShowcaseReport`); the health score stays admin-only. Why: one transparent score, no divergent formulas.
- Signed image variants are created only through `src/lib/storage-image.ts`, with one fallback signature of the original when transformation fails. Why: consistent dimensions and no broken media when resizing is unavailable.
